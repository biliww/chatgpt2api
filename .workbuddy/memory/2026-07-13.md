## 修复：`uv run main.py` 启动报 `'NoneType' object has no attribute 'routes'`

- 根因：`api/register.py` 的 `create_router()` 创建了 `router` 并挂好全部路由，却**漏写 `return router`**。Python 函数无显式 return 默认返回 None → 模块底部 `register_optional_router(create_router())` 把 `None` 注册进 `_OPTIONAL_ROUTERS` → `api/app.py` 循环 `include_router(None)` 抛错。
- 修复：在 `create_router()` 末尾补 `return router`（api/register.py 第 88 行，函数体内正确缩进）。
- 教训：自注册式（import 副作用）路由模块务必显式返回 router；建议在 `register_optional_router` 内加 `assert router is not None` 防御，避免静默注册 None。

## 修复：获取临时邮箱失败 Expecting value（tempmail.lol API 已改版）

- 现象：启动后每条都报 `获取临时邮箱失败：Expecting value: line 2 column 9 (char 9)`。这是 `JSONDecodeError`，根因是 `acquire()` 的 `resp.json()` 解析失败。
- 根因（经 WebFetch 实测确认）：**tempmail.lol 的 API 已改版**。旧接口 `GET /v2?action=genRandomMailbox` 现在返回 HTML 文档页（而非 JSON），所以 `resp.json()` 失败。
  - 新版创建邮箱：`POST {api_base}/v2/inbox/create` → `{"address","token"}`（旧版返回 `email/token/login/password`）。
  - 新版读取邮件：`GET {api_base}/v2/inbox?token=` → `{"emails":[{"subject","body","html",...}],"expired"}`（旧版 `GET /v2/{token}` 返回 `{"mail":[...]}`）。
- 修复 `services/register/mail_provider.py` 的 `TempMailLolProvider`：
  - `acquire()` 改用 `POST /v2/inbox/create`（带 `Content-Type: application/json` + `Accept: application/json`），返回取 `address`/`token`。
  - `_fetch_mails()` 改用 `GET /v2/inbox?token=`，返回取 `emails`。
  - 新增 `_parse_json()`：JSON 解析失败时抛出带 HTTP 状态码与响应体前 300 字符的 `RuntimeError`，便于诊断非 JSON 响应（如再次改版/拦截页）。
  - `wait_for_code`/`wait_for_message_text` 的文本拼接改用 `body`/`html`（新版无 `text` 字段），`openai_register.py` 只用 `address.address` 与 `wait_for_message_text`，未依赖被移除的 `login`/`password`，故无回归。
  - api_key 仍通过 query `?api_key=` 传递（`_auth_params()`）。
- 备注：本回合 Bash 工具持续故障未能实跑 `acquire()` 验证，改动已 Read 复核落盘、逻辑对照官方文档（tempmail.lol/api）推演正确；需用户本地 `uv run main.py` 后点启动验证。
